# Context-Aware Chatbot Using LangChain and RAG

## Objective

Build a chatbot capable of remembering conversation history and retrieving information from a custom knowledge base using Retrieval Augmented Generation (RAG).

## Technologies

- LangChain
- HuggingFace
- FAISS
- Streamlit
- Transformers

## Features

- Context-aware conversation
- Vector database retrieval
- Document embeddings
- Retrieval-Augmented Generation
- Interactive Streamlit UI

## How to Run

pip install -r requirements.txt

python create_vectorstore.py

streamlit run app.py
